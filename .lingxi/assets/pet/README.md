# 桌宠 P0 美术资源

本批按 `desktop-pet-art-asset-spec.md` v3 的已裁定范围交付：P0-1～P0-4。资源统一放在用户指定目录，不改运行代码。

## 使用入口

- `front-standing.png`：2048×3072 站姿母版，锚点 `(1024,2908)`。
- `expr/E1_default.png`～`E8_sleepy.png`：8 张同画布整头贴片，头区以外透明。
- `body-without-head.png`：与贴片无重叠的身体底图。
- `runtime/composites/*@1x.webp`、`*@2x.webp`：可直接显示的完整表情帧，分别为 160×240、320×480。
- `runtime/expressions/`：同尺寸运行时整头贴片；与 `runtime/body-without-head*` 搭配。
- `psd/pet_p0.psd`：同画布的立绘、7 个可切换脸区替换层、7 组材质色板。默认只显示立绘；切换表情时只打开对应一层。它是 P0 合成工程，未按部件语义拆层。
- `palette.json`、`qa/palette.png`：材质色值及采样位置。站姿未露出肉垫，该项单独取自设定稿并注明来源。
- `manifest.json`：尺寸、用途、锚点、表情映射、文件摘要与延后范围。
- `qa/preview.html`：本地交互验收页，提供深浅背景、眨眼、E1→E3→E7 连切 10 轮。
- `qa/expressions-208px.png`、`qa/faces-detail.png`：实际可见高度约 208px 的对照与面部放大图。
- `qa/validation-report.json`：机检及金丝雀结果。

## 合成约定

优先直接使用 `runtime/composites` 完整帧。使用 PNG 分层时，将去头身体和整头贴片在同一原点合成；两者像素区域无重叠，E1 重组与母版完全一致。不要将整头直接叠在完整立绘的半透明轮廓上，否则会加深边缘。

头部导出区域为源图 `y<744`，对应母版 `y<1488`；下方长发、围巾及身体固定在底图。所有表情使用完全相同的轮廓和 alpha，只有眼、口及腮红变化。此区域适用于方案 A 的同位置表情替换，不用于独立旋转头部。

运行时先缩放完整帧再分离：@1x 分界为 `y=116`，@2x 为 `y=233`。每档身体与表情贴片重组后，透明像素 RGB 归零，再逐像素对比对应完整 WebP 帧，结果完全一致；WebP 编码器可以改写不可见 RGB，不影响透明度和显示效果。

眨眼三态按规格取 E1 / E8 / E2 的**眼区**，不能用困倦整头替代半闭眼，否则嘴也会变化。源图眼区定位见清单，坐标放大 2 倍即母版坐标。独立眼皮、眉与视线偏移未纳入本批。

## 来源与处理

设计依据：用户提供的 `E:\user\image\桌宠.png`，本次实读为 **1536×1024、横向正读**；规格书中「1024×1536、需旋转」是旧状态。本次未再次旋转。

几何依据：桌宠开发工作区中的 `docs/assets/desktop-pet/v2/front-standing.png`，原图归档在 `source/front-standing-v2.png`。所有脸区通过内置 imagegen 的局部编辑生成，提示词及原始输出路径记录在 `prompts.json`，选中的面部源像素保存在 `source/edits/`。生成器改动区域外的像素全部丢弃，使用固定蒙版合成回 v2；眨眼仅应用眼区。

母版使用原图像素精确复制 2 倍，不声称新增绘画细节。透明度 ≤8 的低强度残点清零，≥248 的内部像素统一为不透明，孤立且不超过 4 像素的噪点删除；保留其余抗锯齿和发丝。透明像素的 RGB 清零，避免图片查看器显示隐藏底色。可见边界以 alpha≥128 统计，对齐原 v2 的容差要求。

规格书眼睛高度 `y≈780` 与 v2 实际位置不符；本批以 v2 双眼的实际位置为准，未移动眼睛去迎合该参考值。规格书 M9 同时要求「头外透明」和「非头部与立绘一致」，本批按无重叠重组后的完整图比对；E1 重组零差异，其他表情仅允许脸区变化。

PSD 由 [ag-psd](https://github.com/Agamnentzar/ag-psd) 写入并复读。立绘图层像素无损；PSD 缓存合成图在半透明边缘有白色衬底往返量化，RGB 最大差值见验收报告，透明度不变。交付 PNG 与 WebP 不经过该缓存。

## 复现与验证

在本目录安装依赖后执行：

```powershell
npm install
npm run build
npm run verify
npm run verify:canaries
```

当前机器也可复用既有桌宠工作区的 sharp 和 `.lingxi/tmp/pet-art-tools` 的 PSD 库；缺依赖会显式失败。构建输入均已包含，不需要再次调用生成器。

机检递归核对资源清单、SHA-256、RGBA8、色彩声明、同画布、完整外边缘透明、v2 可见边界、8 档轮廓、非脸区一致性、PSD 复读、单 PNG 2MiB / 清单内模型 25MiB 上限。预算统计清单内交付资源，包含 PSD 和运行时文件；参考图、差分源图和验收预览单独存档，不计入模型。

金丝雀主动注入索引色头、含 NUL 的文本块、不透明角点、清单与磁盘同时漏掉一档表情、嵌套未登记文件，必须全部被拒绝才报告通过。深浅背景及 208px 预览另行目视检查；最终观感以用户审阅为准。

## 本批以外
