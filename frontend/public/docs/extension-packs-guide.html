LingXi 自定义扩展包开发与加载指南

适用于桌面端自定义本地扩展包（纯静态资源包：CSS / 字体 / 图片），支持跨类目自由叠加与热切换。

1. 快速加载自定义扩展包

在客户端打开 设置 → 扩展包，底部的「自定义本地扩展包目录」支持以下两种目录形态，只需输入绝对路径（或点击「选择文件夹」）即可加载：

  • 多包合集目录（推荐）：例如 D:\my-lingxi-packs，其下每个子目录为一个独立扩展包（均含 manifest.json）。系统会一次性扫描所有合法子包，并按 category 自动分发到对应类目。
  • 单个扩展包目录：例如 D:\my-lingxi-packs\my-theme，目录根下直接放置 manifest.json。
持久化与自动恢复 已添加的自定义目录会保存在本机配置中，重启客户端时会自动重新扫描并恢复你启用的扩展包。若修改了本地 pack.css，点击目录旁的「刷新」并重新点选一次即可立即生效。

2. 目录结构与 manifest.json 规范

一个标准的纯资源扩展包目录结构如下：

目录结构示例 
D:\my-lingxi-packs\
├── my-ocean-theme\
│   ├── manifest.json       # 必填：元数据与类目声明
│   ├── pack.css            # 必填：样式入口（可在 manifest.json 中指定 entryCss）
│   └── assets\             # 可选：图片、背景或字体资源（自动内联为 data URL）
│       └── bg.webp
└── my-font-pack\
    ├── manifest.json
    ├── pack.css
    └── fonts\
        └── custom.woff2

manifest.json 完整字段说明：

字段 必填 说明
id 是 唯一标识，仅允许小写字母、数字和短横线 ^[a-z0-9][a-z0-9-]{0,62}$。
category 是 所属类目：theme | font | background | sidebar | input | component。
name 是 扩展包展示名称。
hostApiVersion 是 固定填 "1"，版本不匹配时宿主会安全拒绝加载。
version 否 版本号（如 "1.0.0"），默认 "1.0.0"。
description 否 扩展包一句话介绍。
entryCss 否 样式入口相对路径，默认为 "pack.css"。
capabilities 否 能力标签数组，如 ["明暗配色", "本地定制"]。
preview 否 卡片右上角三色预览点：{ canvas, surface, accent, text }。
fontPreview 否 字体包预览样本：{ sample, family }。
manifest.json 最小模板 
{
  "id": "my-ocean-theme",
  "category": "theme",
  "name": "深海蔚蓝",
  "description": "自定义深海蓝明暗双态主题包",
  "version": "1.0.0",
  "hostApiVersion": "1",
  "capabilities": ["明暗配色", "自定义"],
  "preview": {
    "canvas": "#06111c",
    "surface": "#0b1c2c",
    "accent": "#38bdf8",
    "text": "#f0f9ff"
  },
  "entryCss": "pack.css"
}

3. 六大类目开发指南

不同类目之间互不冲突、可同时叠加生效，同一类目内互斥单选。建议每个扩展包只专注于自身类目的职责。

theme · 主题皮肤 覆盖全局 --lx-* 颜色、表面、边框与强调色变量。
font · 文字字体 通过 @font-face 与 --font-sans / --font-lx-code 定制字体。
background · 主页背景 针对 .lx-chat-background 添加渐变或本地背景图。
sidebar · 侧边栏 针对 aside.border-r 定制侧边栏圆角、毛玻璃与导轨效果。
input · 输入框 针对 [data-slot="chat-input-card"] 定制输入卡片质感与聚焦光环。
component · 组件与动效 定制流式文字 arrival、思维链呼吸等动效时长与曲线。

3.1 theme · 主题皮肤

LingXi 默认暗色，亮色模式通过 html.light, html[data-theme="light"] 切换，建议同时提供暗色与亮色两套变量：

packs/my-ocean-theme/pack.css 
:root {
  --lx-canvas: #06111c;
  --lx-canvas-subtle: #091826;
  --lx-surface: #0b1c2c;
  --lx-surface-elevated: rgba(13, 32, 50, 0.94);
  --lx-surface-sunken: #07131f;
  --lx-border-subtle: rgba(56, 189, 248, 0.16);
  --lx-border-default: rgba(56, 189, 248, 0.24);
  --lx-border-focus: rgba(56, 189, 248, 0.85);
  --lx-accent: #0ea5e9;
  --lx-accent-hover: #38bdf8;
  --lx-accent-pressed: #0284c7;
  --lx-accent-soft: rgba(14, 165, 233, 0.16);
}

html.light,
html[data-theme="light"] {
  --lx-canvas: #f2f9ff;
  --lx-canvas-subtle: #e6f3ff;
  --lx-surface: #ffffff;
  --lx-surface-elevated: #ffffff;
  --lx-surface-sunken: #eaf4ff;
  --lx-accent: #0284c7;
  --lx-accent-hover: #0ea5e9;
  --lx-accent-soft: rgba(2, 132, 199, 0.12);
}

3.2 font · 文字字体

支持引用扩展包目录下的 .woff2 / .woff / .ttf 字体文件（加载器会自动内联）：

packs/my-font-pack/pack.css 
@font-face {
  font-family: 'MyCustomSans';
  src: url('./fonts/custom-sans.woff2');
  font-display: swap;
}

:root {
  --font-sans: 'MyCustomSans', 'PingFang SC', ui-sans-serif, sans-serif;
  --font-lx-code: 'JetBrains Mono', 'Cascadia Mono', ui-monospace, monospace;
}

body {
  font-family: var(--font-sans);
}

3.3 background · 主页背景

主页背景容器类名为 .lx-chat-background。若使用本地图片，建议保留 var(--lx-canvas-image, none) 以兼容用户在通用设置里手动上传的自定义图片：

packs/my-bg/pack.css 
.lx-chat-background {
  background-image:
    var(--lx-canvas-image, none),
    url('./assets/wallpaper.webp');
  background-size: cover;
  background-position: center;
}

3.4 sidebar · 侧边栏

侧边栏根节点可通过 aside.border-r 命中，推荐复用 --lx-* 变量以自动适配亮/暗主题：

packs/my-sidebar/pack.css 
aside.border-r {
  margin: 8px 0 8px 8px;
  height: calc(100% - 16px) !important;
  border-radius: 18px;
  border: 1px solid var(--lx-border-subtle) !important;
  background-color: color-mix(in srgb, var(--lx-surface) 84%, transparent) !important;
  backdrop-filter: blur(18px);
  box-shadow: var(--lx-shadow-2);
}

3.5 input · 输入框

输入框卡片根节点带有稳定锚点 [data-slot="chat-input-card"]，可自定义圆角、毛玻璃与聚焦态：

布局约束提醒 请勿修改输入区外层的 max-w-lx-chat 列宽，否则会导致输入框与上方消息列表左右不对齐。
packs/my-input/pack.css 
[data-slot="chat-input-card"] {
  --pb-radius: 22px;
  border-radius: 22px !important;
  background: color-mix(in srgb, var(--lx-surface-elevated) 80%, transparent) !important;
  backdrop-filter: blur(16px);
  border: 1px solid var(--lx-border-default) !important;
}

[data-slot="chat-input-card"]:focus-within {
  border-color: var(--lx-accent) !important;
  box-shadow: 0 0 0 3px color-mix(in srgb, var(--lx-accent) 20%, transparent);
}

3.6 component · 组件与动效

可覆盖流式输出与思维链动画类名：

packs/my-stream/pack.css 
/* 流式新增文字渐显 */
.codex-text-arrival {
  animation-duration: 180ms !important;
}

/* 思维链运行态呼吸 */
.stream-thinking-content.is-running {
  animation-duration: 240ms !important;
}

/* 卡片入场动效 */
.animate-blur-in {
  animation-duration: 200ms !important;
}

4. 静态资源引用与内联

主进程在读取本地自定义扩展包的 pack.css 时，会自动扫描以 ./ 开头的相对路径 url('./...')，并将其转换为 data: Base64 内联到样式表中。

  • 支持的静态资源扩展名：.woff2、.woff、.ttf、.png、.jpg、.jpeg、.webp、.svg。
  • 请使用相对路径（如 url('./assets/bg.webp')），不要写死本机磁盘绝对路径（C:\...）。

5. 安全边界与限制

  • 本地自定义目录仅支持纯资源包（manifest.json + CSS + 静态字体/图片），主进程会自动拦截并拒绝执行外部 .js / .mjs 脚本。
  • 所有资源路径均做目录穿越校验，禁止访问扩展包目录以外的文件；单个静态资源上限为 10 MB。
  • 自定义目录中的包 id 建议使用独特前缀（如 custom-xxx），避免与内置扩展包重名。
