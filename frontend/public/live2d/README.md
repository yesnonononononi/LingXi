# Live2D 模型资源目录（约定）

桌宠的 Live2D 模型资源放这里，当前**为空占位**——阶段一只做窗口骨架，刻意没装任何
Live2D 运行时依赖（`pixi.js` / `pixi-live2d-display` 等），免得在窗口手感还没验证之前
就把包体积和调试复杂度抬上去。

## 将来怎么放

```
public/live2d/
  <模型名>/
    <模型名>.model3.json     ← 入口清单，运行时从这里加载
    <模型名>.moc3
    textures/…
    motions/…
    expressions/…
```

约定：

- 一个模型一个子目录，目录名与 `model3.json` 同名，避免多个模型混在一起。
- 只放**模型资源**与 `model3.json`，不放脚本；加载逻辑将来写进 `src/pet/`。
- 体积较大的模型（>10MB）不要进 git，走额外分发或压缩后再入库。
- 阶段二接入时，`src/pet/main.ts` 里的假宠物圆形命中区要换成模型包围盒命中区，
  但**点击穿透、自定义拖拽、位置持久化这三条真机手感不变**——这也是本阶段先做骨架的原因。
