## 新增与改进

- **上下文事实卡片**：上下文被改写或重建时，对话里直接出现系统通知卡片（左上角浮层样式），说明发生了什么以及改了哪几类内容；不再需要用户自己去日志里翻上下文什么时候被动过。
- **浏览器工具截图**：截图视口与右侧预览面板宽度解耦，按当前页面实际视口出图，不再被窄面板裁掉右半边。
- **计划模式**：`create_plan` 收进默认工具集，开启/关闭计划模式不再改变工具声明，避免每切一次模式就打掉一轮前缀缓存。

## 问题修复

- 安装包里的原生对话框标题仍显示历史包名「aether-agent-chat」，已改为当前产品名。
- 删除会话改为幂等：重复删除不再报错，失败时必须说清原因；agent 内部报错不再弹成用户对话框。
- 原生 `alert` / `confirm` 全部迁到统一确认框；整树删除、整库清空改用独立的超时预算，慢盘上不再误判失败。

## 工程与稳定性

- 框架升级到 harness `1.1.8-SNAPSHOT@0772119`：上下文事件拆分为「改变」与「重建」两个事件面，并携带执行级权威修订号 `contextRevision`；前端只按修订号去重，不再拿载荷内容拼身份，断线重连与重启后不会重复渲染同一条事实。
- 补齐上下文装配与卡片身份的守卫用例，变异验证确认断言会因缺陷变红。
