## What's new

- The Windows installer is self-contained now. The sandbox runtime — Node.js 24.22.0, Git for Windows and the MXC SDK — ships inside the app, and the backend resolves it from the installation directory. A fresh machine needs no external runtime deployment and no first-run elevation before the sandbox works.

## Improvements

- Packaging validates the bundled Node.js against the SDK's Windows stdio floor (24.21.0+) and refuses to ship a runtime that does not meet it.
- The release build provisions the bundled runtime from version-locked public sources (`frontend/vendor/runtime.lock.json`) and caches it in CI, so local and CI artifacts carry the same components.
- The window icon on Windows uses the product ICO through `nativeImage`; splash and tray wording refreshed.
- Upgrade the harness framework and pin the exact commit: host OS detection is centralized, file responses are sized to cover base64 encoding, and compaction events are tagged with the band that produced them.
- Agent profiles support an avatar (emoji or image URL), and the v8 schema migrations land for agent avatars, MCP launch commands with environment and headers, session context-window controls and richer tool-call records.
- A prompt that was not accepted by the backend can be removed and resent from the chat, and model-driven turns state which agent preset decided their model.
