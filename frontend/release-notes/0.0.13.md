## 新增与改进

- 终端支持前台、后台两种运行方式；后台任务可查看实时输出、等待结果和确认停止。
- 后台任务结束后自动向发起执行提供结果摘要，支持根代理、子代理和未绑定 Agent 的模型；等待期间保存检查点，完成后继续处理。
- 聊天界面新增后台任务面板，展示运行状态、用途和输出，支持受控删除已结束任务记录。
- 支持暂停、恢复及编辑重发，并改进发送按钮和提示词优化交互。

## 问题修复

- 修复停止命令响应不及时、等待后台结果阻塞查询与停止的问题。
- 修复首段输出前取消或失败时缺少状态提示，以及恢复后终态提示未清除的问题。
- 改善 Windows 沙箱的工具路径查找和宿主环境继承；文件预览支持具有本机目录的沙箱工作空间。
- 统一工具消息、执行身份与结果处理，并锁定框架源码提交，使发布构建与依赖来源一致。

## 任务与恢复规则

- 查询和停止使用当前会话的任务归属；停止确认失败时保留实际运行状态。
- 任务状态与输出由运行时维护，不能通过手工新增或修改记录伪造执行结果。
- 所属执行尚未结束时保留任务记录，避免删除尚未处理的结果通知。
- 应用重启后不会自动重放命令；无法确认的在途任务标记为状态丢失。
