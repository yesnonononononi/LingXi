## What's new

- Bring your own Anthropic models. Model names containing `claude` are routed to the native Anthropic protocol automatically, so reasoning follows the thinking settings instead of the OpenAI-compatible fallback.
- Reuse the prompt prefix with Anthropic prompt caching. The system prompt and tool definitions are now marked with `cache_control`, so repeated requests read that prefix from the provider cache instead of paying for it again. Cached tokens show up in the usage card below.
- Inspect token usage from a hover card: cache hit details and reasoning tokens now sit next to the prompt and completion counts.

## Improvements

- Persist cache and reasoning token counters with each turn, and show them per turn in the usage panel.
- Compute the cache hit ratio from the input side so the number matches what the provider reports.
- Keep snowflake model IDs as strings, so selecting a model no longer loses precision and writes a corrupted configuration back.
- Fix the jump when expanding a collapsible section (deep thought, process and tool details). The panel used to grow past its final height and snap back; it now expands and collapses smoothly in both directions.
- Remove the always-on background of the usage entry point and unify token units.
- Upgrade the harness framework to 1.1.5 and pin the exact commit in the dependency lock.
