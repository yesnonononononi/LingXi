## 新增与改进

- **输入区改版**：加号分组菜单（MCP / 技能 / 协作按需加载）、权限上拉框、指令框贴底；协作与 `/plan` 统一蓝色徽标，思考强度弹层与权限菜单收进按钮附近。
- **待发送队列**：改为持久化（`pending_task`），支持图片排队、单条继续、原位编辑（可改计划模式 / 模型 / 执行体）与撤销回写；面板抽离成独立组件并接入任务进度扩展槽，轮次结束后提供扩展点。
- **扩展包体系**：类目收敛为「渲染动效 / 任务进度 / 互动卡片」，审批、计划、选择三类卡片插槽化并新增多套内置包（共 12 个）；支持从 GitHub 官方扩展仓与本地绝对路径加载；任务进度三类面板样式可分离，并按 Tab 独立激活。
- **设计画布**：实时微调、设计令牌注入、变体对比、版本历史 diff 与恢复、元素批注、模式切换与元素复制/层级调整、HTML 粘贴与导出交付；原型可绑定工作区文件，交给 AI 继续改。
- **预览面板**：多标签统一面板 + 书签 + 右键菜单；新标签页与浏览页面工具卡片合并；正文里的本地文件链接可直接按行唤起对应文件。
- **会话管理**：会话置顶、标题双击就地重命名、顶部横条重排；清空全部会话改为按表批量删除（无 N+1、无长事务）。
- **手工压缩 `/compact`**：随时把当前会话上下文压一次，直接回显最新用量与重算后的审计结果；用量不足 20% 直接拒绝受理，压缩期间有明确进度反馈并挡住发送，不会与上下文写回抢同一份正文。
- **MCP**：远程服务支持 OAuth 授权；设置页选填项收进高级折叠、强调色统一；状态行可直接启用 / 停用 / 重新连接；内置浏览器提供本地 Streamable HTTP MCP，并增强 wait / scroll / text click / select fill / hoverOnly 与截图时机。
- **工具**：新增 `search_files` 与 `delete_file`，`read_file` 输出改为带行号的 1-based 文本；文件类工具统一走工作区边界校验；下线 `web_search` 及其检索实现。
- **权限**：`AgentPermissionMode` 取代原 sandbox 三档，按执行环境如实展示档位语义与越界提示。
- **个性化**：可配置快捷键与冲突检测；`Ctrl+\` / `Cmd+\` 一键切换侧预览面板。
- **图片**：预览接入右键菜单（复制 / 保存），用户历史图片放大统一走全局灯箱。

## 问题修复

- 恢复长会话时，清单提醒的证据扫描遇到只发工具调用、没有正文的助手消息会抛 NPE，导致整轮连同已恢复的 433 条消息一起作废。
- `/compact` 沿用 10 秒默认超时：服务端已压完并写回上下文后，客户端仍判定失败（再点又被「用量不足 20%」拒绝）。
- 上下文占用环在未采集用量时凭空消失、压缩进行中切换会话后提示不消失。
- 待发送消息编辑、队列回写与互动卡片详情展开相关的交互错位。
- 预览面板开合动画逐帧重排闪烁、快速收起后重开白屏。
- H2 偶发 BUSY_SNAPSHOT、布尔列类型不一致、关闭期压缩引起的退出变慢。
- MCP OAuth 历史配置字段兼容、连接状态谎报未连接。
- 窄窗口下右侧面板挤扁主会话列表与输入框等排版问题。
