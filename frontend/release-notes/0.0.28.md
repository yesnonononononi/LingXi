## 新增与改进

- **扩展包类目补全**：类目白名单从 6 项补齐到 8 项（含任务进度、交互卡片等），本地扩展包不再因为类目不在白名单而被静默丢弃，在线注册表也不再报「非法扩展包类目」。
- **侧边栏可覆盖锚点**：应用给侧边栏开放了一组稳定的 `data-slot` 锚点（侧边栏、会话行、工作区分组、固定分组、菜单行等），并写进应用内文档；自定义样式不再依赖 Tailwind 原子类或猜测 DOM 结构。
- **输入栏命令精简**：斜杠命令菜单只保留常用项（`plan` / `compact` / `export` / `agent` / `optimize-prompt`），模型、团队、权限、MCP、技能、设置等入口仍在原处，不再占用斜杠命令。

## 消息与过程流可换皮肤

- **新增第 9 个扩展包类目 `chatMessage`**：对话中的用户气泡、助手正文、操作栏，以及过程区的思考步骤、工具调用行与子代理协同条都能被替换；拆成 5 个子 Tab 各自启用，可任意组合叠加，也能与主题包、背景包一起联动换肤。
- 应用同时给消息列表与过程区开放了 8 个稳定的 `data-slot` 锚点（`message-item` / `user-message-bubble` / `assistant-body` / `process-panel` / `process-segment` / `process-thought` / `process-tool` / `process-sub-agent`），纯 CSS 扩展包不写一行 JS 也能改样式。
- 随包内置两套官方皮肤：**TerminalTUI** 把消息流与过程流改成终端语汇（等宽字形、`user@lingxi:~$` 提示符、`>> think` 思考行、单行工具调用与 `in/out/cache/think` 遥测脚注）；**CyberWireframe** 走直角线框与导轨质感，纯 CSS 实现。
- 扩展开发文档补上「消息与过程流 (chatMessage)」整章：子 Tab 与锚点对照、Slot↔Props 契约表、Slot Props 字段速查、本地纯资源包的目录结构与 manifest 字段逐项说明，还标出两个易错点（纯资源包只加载 CSS、CSS 相对资源会被内联）。

## 问题修复## 问题修复

- **产品文档位置写进系统提示词**：指明产品文档在应用内 `/docs`，并给出本机镜像位置；回答「这个功能怎么用」时先查文档，不再凭印象编造，缺文档时如实说明。
- **后端构建环境写进系统提示词**：`JAVA_HOME` 指向客户端内置运行时会让 Maven 报 `No such compiler 'javac'`，现在提前说明症状与排查动作，避免被误判成代码或依赖坏了。
- **重发不再重拼上下文**：重发消息复用目标轮次已有的上下文规格，记忆段不再带计数，避免每次重发都重新拼装一遍上下文。
- **历史包名清理**：文档与提示词里不再出现旧包名，改按运行中的应用名推导用户数据目录。
- **计划摘要不再改写正文**：计划卡的一行摘要以前把 `-`、`_`、`|` 一律当 Markdown 标记替换成空格，`plan-0`、`lingxi-harness-agent` 这类标识符会被摘要改写成「plan 0」。现在只剥标题、列表、强调、链接这些真正的结构标记。

## 工程与稳定性

- 产品事实类提示词段（渲染语法 / 产品文档 / 后端构建环境）收口到 `ProductPromptSections` 统一装配与排序，新增段落不再需要改动提示词构建器的构造签名。
- 上述提示词段均配了契约测试，并做了变异验证：改动顺序、漏掉关键说明、段落带多余空行都会让断言变红。
- 动效统一到项目自有的 `.lx-live-dot`：输入栏压缩提示、Neon HUD 背景面板与待办面板不再各自使用 Tailwind `animate-pulse`，呼吸节奏只由一处定义，换主题或调时长不用满仓找类名。
- 状态点样式收敛到 `cardDotClass` 单一映射：进行中、待确认等状态不再在模板里手写颜色 + 动画组合。
- 已登记工具不再落到「未知」齿轮兜底图标：MCP 工具调用有了独立的插头图标，「MCP 工具清单」与「调用 MCP 工具」不再共用同一个图标。
- 团队名徽章宽度收回 `style.css` 的 `.lx-team-badge-name`，不再在模板里写死 `max-w-[10rem]`。
- 修掉几处测试自身的技术债：`apiConfig` 在没有 `localStorage` 的运行环境不再抛 `ReferenceError`；组件测试的临时 `.mjs` 编译产物按进程隔离，避免并发互删导致随机失败；侧边栏固定会话分区的可选参数补上默认值；渐进淡入用例显式声明动效偏好，不再继承宿主「减少动态效果」设置。
