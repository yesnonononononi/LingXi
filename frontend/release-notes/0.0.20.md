## 新增与改进

- 增加无用执行数据清理入口，保留重发、审批恢复和后台任务仍在引用的快照。
- 模型与 MCP 配置改为不可变版本引用，新执行快照不再直接保存这两类连接配置，恢复时沿用原版本。
- 会话列表优先展示运行中的会话，同组按更新时间倒序排列。
- 完善输入区与侧边栏的组件扩展接口，支持复制消息为引用。

## 问题修复

- 子会话切换和历史加载保留已有消息，避免覆盖正在到达的实时内容。
- 执行依赖加载失败时明确结束执行并通知界面，避免长期停留在“思考中”。
- 修复开发环境设置、执行清理接口的代理路由，并统一对话列宽。

## 兼容说明

- 旧执行快照继续支持恢复；兼容路径已标记弃用，存量历史不会在升级时批量重写。
- 本次配置引用调整不包含通用消息脱敏、整库凭据加密或完整运行环境冻结。
