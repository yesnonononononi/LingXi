## 新增与改进

- 主会话与子会话底部统一展示后台任务、任务清单胶囊，支持展开进度、查看输出及停止、删除后台任务。
- 胶囊和展开面板增加淡入淡出与轻微位移动画，并遵循系统的减少动态效果设置。
- 新增执行清单工具与收尾提醒，保留成功、失败、跳过和已删除清单的真实状态及历史。
- 子会话名称旁显示独立的上下文用量，切换成员时同步对应会话的数据。
- 新增专用压缩模型配置，可分别调整压缩模型与输出上限。
- 侧栏通过应用级事件流同步会话运行、挂起、完成和已读状态。
- 统一灰阶主题，并将多类互动卡片收敛为可折叠的展示方式。

## 问题修复

- 当前打开的会话不再显示侧栏状态标记，收到完成事件后会再次确认已读。
- 修复子会话断线重连后历史缺口、加载后的滚动定位，以及委派任务被显示成普通用户消息的问题。
- 过程摘要在文本与工具活动收尾后更新，运行中的命令继续显示动态进度。
- 待确认卡片优先展开，提问作答按实际可用状态推进，减少过早停止查询造成的交互停滞。
- 修复会话版本号跨位数时的状态回退，以及已读会话丢失运行动画的问题。
- 修复失效压缩模型配置无法取消、配置参数读取相互影响的问题。
- 修复 Windows 开发版任务栏图标和删除会话后的执行收尾问题。
