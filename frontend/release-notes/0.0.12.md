## 新增与改进

- 新增安全中心二级设置页，将沙箱设置、文件保护、命令安全和网络设置集中管理，沿用现有界面风格。
- 文件保护和命令规则支持预设、自定义、启停与排序；文件规则支持允许或禁止，命令规则支持允许、询问或禁止。
- 沙箱允许访问其他工作区的普通目录，同时通过 Windows 原生策略拒绝受保护路径的内容访问和修改。
- 框架升级至正式发布的 1.1.7，并锁定源码提交，保证本地与发布构建使用一致的框架来源。

## 问题修复

- 修复沙箱终端中文、emoji 输出乱码及部分 UTF-8 输出解码异常。
- 修复文件工具的文本编码处理和长链接消息撑开聊天区域的问题。
- 改善 Windows 目录枚举命令在跨工作区访问模式下的兼容性。

## 当前保护范围

- 本版受保护文件采用直接拒绝策略，文件访问审批尚未开放；规则变更对新执行生效，已开始的执行保持原策略。
- 受保护目录的名称和部分元数据仍可能从父目录可见，目录内部枚举和文件内容访问会被拒绝。
- 默认允许普通出站网络访问，沙箱入站和宿主回环仍受限；网络细粒度规则后续完善。
- 宿主管理的 MCP 连接尚未纳入上述原生文件隐私隔离。
