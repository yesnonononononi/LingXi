## What's new

- Attach up to nine images to a single message. Select multiple files or paste images, preview your attachments, and remove them individually before sending.
- View every attached image in your messages and conversation history, with the original image order preserved.
- Use a shared image limit enforced by the backend and displayed in the input area.

## Improvements

- Display formatted release notes in Settings, with update verification metadata hidden from the visible changelog.
- Show a neutral gray status when the installed version is already up to date.
- Prevent duplicate user messages during conversation history reconciliation.

## Build reliability

- Build the backend against pinned Harness and DDD source commits. Framework changes no longer need to be published to Maven before CI can build the application.
