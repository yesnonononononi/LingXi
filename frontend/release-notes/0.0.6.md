## What's new

- **Collaboration mode.** Delegating work to a sub-agent no longer freezes the chat. The agent hands the task off and the conversation stays usable while the sub-agent works; its progress lives in its own side panel, and what it produces comes back to you as messages. The hand-off itself appears in the thread as a clear "you have a pending task" note, with the full brief expandable underneath.

## Improvements

- The sub-agent panel shows the sub-agent's real name and its current state from the moment it starts, instead of a placeholder.
- Removed the blocking delegation wait card. Nothing in the thread pretends the conversation is on hold while a sub-agent is still working.
- A message's body is now taken only from a completed concluding answer, so intermediate reasoning and tool chatter no longer leak into the message text.
- Plan and choice cards show a loading state while their content is still arriving, instead of rendering empty.
- Under the hood: upgraded the agent framework to 1.1.3 (completion hook, live compaction counters, memory access contracts) and fixed three backend defects — a decision-replay fact that was lost when a card was read back from the database, a resume dispatcher that could stay permanently blocked after a rejected submission, and a conversation snapshot that was silently dropped when a turn had no content blocks yet.
