## What's new

- Custom model providers. Add your own OpenAI-compatible provider, give it a base URL and key, and attach models to it. Model settings are now grouped by provider, so a model name that exists in two places is no longer ambiguous.
- Batch model assignment for agents. Select several agents in the agent list and point them all at one base model in a single action.
- Commander can now check on teammates. A new `peek_teammate_state` tool reports whether a teammate is running, suspended or idle, plus its last outcome, without waking it. It is commander-only and read-only: looking at a teammate never starts a new execution.
- Time-aware greeting on the empty chat screen, with the personalization name when one is configured.
- Up to 15 images per execution, raised from 10.

## Improvements

- A single theme token layer (`--lx-*`) now drives colors and surfaces, so light and dark mode stay in sync instead of each component picking its own shade.
- The unified model dropdown collapses provider groups by default, keeps the provider name legible, and its border and arrow follow the theme.
- Fixed clipped descenders in the input footer text.
- Fixed tool rows shifting left when a call has no expandable detail: the chevron column now always reserves its width.
- Sidebar visibility, expansion, grouping and actions are now separate composables with a behavior baseline behind them, so further changes to the sidebar can be verified instead of eyeballed.
- Sub-agent tools share one base class for identity resolution and membership checks, which keeps the delegation and state tools consistent.
