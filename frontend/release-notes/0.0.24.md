## 新增与改进

- **主页背景可自定义**：设置中支持选择图片背景，带缩略图预览、自定义上传与一键清除。
- **MCP 高级连接容错**：每个 MCP 服务可单独指定协议版本、开关自动健康检查、调整健康检查与重连间隔。当远端服务拒绝协议探测时，可直接钉死版本，避免反复握手失败。
- **计划书大预览**：计划书支持独立大视图，长文与表格阅读更顺畅。
- **角色提示词输入框**：支持拖拽调节高度，长提示词编辑不再局促。
- **长期记忆容量检查**：模型调用前先检查记忆容量，续轮与恢复场景不再遗漏超限提醒。
- **模型密钥来源**：持久化密钥来源，并在调用时实时读取提供方的 API Key。
- **补充并恢复**：聊天中断后可从补充入口继续，竞争失败的草稿不会丢失。

## 问题修复

- 修复命令批准后仍显示「待处理 / 待确认」状态的问题。
- 修复已删除的后台任务被较早返回的列表响应重新带回界面的问题。
- 修复停止任务时后台任务列表被阻塞的问题（停止与收尾等待已隔离）。
- 修复大图用作背景时 CSS 变量被丢弃的问题（改用 Blob URL）。
- 修复 dark 模式下过程行文字光晕被裁成矩形灰盒的问题。
- 修复复制回写游标在恢复后只读属性场景下的兼容问题。
- 修复 MCP 健康检查持续失败导致运行日志无限增长的问题。
- 修复开发态文件监听因 Electron 验证缓存而退出的问题。
- 修复恢复补充要求时自动唤醒丢失输入的问题。

## 工程与稳定性

- 视觉回归门禁（G-5 / G-10）场景解耦，判定抽成纯函数并支持三档退出码。
- 主题令牌映射断言补齐；背景插槽契约与默认态零写入纳入 L2 锁定。
- 并行工具参数格式异常不再污染会话历史。
