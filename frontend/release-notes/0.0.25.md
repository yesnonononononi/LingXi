## 新增与改进

- **用量审计面板**：会话级 token 用量按「消息构成 / 工具定义 / 记忆正文 / 用户附件」分层归因，工具逐项明细可展开滚动，记忆正文用量直接可见，并明确每个占比的分母是上下文上限。
- **指令预测**：输入框按上下文预测下一步指令，以占位文本呈现、Tab 一键补全；子会话、未正常完成的轮次与已开新一轮的会话不再误预测。
- **编辑记录与行级差异**：工具改动按「基线 + 增量 diff」落库，行号持久化，重启后本轮改动清单仍可重建；轮次末尾可查看改动文件并整轮撤销。
- **会话上下文外置**：长会话的消息正文改存 JSONL 文件，库内只留标识；删除会话时级联清理检查点、上下文、图片与基线目录。
- **预览面板**：支持多标签与独立导航历史、导入本地 HTML、双击就地编辑与字号/背景/圆角实时调整，并接入原型画布；内置浏览器可右键「Show with Agent」把页面与需求一起交给模型。
- **记忆 wiki**：三层记忆按项目隔离，支持关键词检索与按需加载，项目公约与 wiki 索引统一进入系统提示词。
- **生图**：配置生图模型后可在工作区直接出图，图片进入消息历史并支持大图预览。
- **超长文本转文档卡**：粘贴大段文本自动收成文档卡片，输入框不再被淹没。
- **流式输出开关**：模型请求是否流式输出改为模型设置页可配置。
