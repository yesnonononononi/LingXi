## 新增与改进

- 过程区改为分段折叠：文本块之间的工具活动各自成段，运行中实时显示活动预览，折叠以整轮为单位。
- Mermaid 图表按内容块渲染，图表不再伪造语言徽标，长图也不会打断流式消息的排版。
- 运行态指示收敛到一层样式，用令牌驱动的扫光高亮表达「正在运行」。
- 主页背景抽出为独立背景层，明暗主题只靠背景令牌切换，可整体替换。
- 工具 Schema 改为类型化注解声明，工具契约与执行组件就近放置，新增工具不再手写 JSON Schema。
- 网页检索结果超过工具输出上限 110% 才调用摘要模型；摘要不可用时返回带标记的裁剪原文，不再把原始 JSON 当摘要塞给模型。
- 多题选择卡改为顺序作答：默认停在第一道还没答的题，答完一题自动进入下一道未答题。

## 问题修复

- 多题选择卡会停在一道已答的题（或直接跳到最后一题）上，前面的题明明还没作答；现在落点由「第一道未答的题」决定，进位也只往前走。
- 过程区去掉重复的失败计数，失败状态只在活动行上表达一次。
- 长活动标签在窄列宽下不再溢出过程区标题。
- 编辑保留 CRLF 的文件时不再改写本次未触碰的字节。
- 执行快照回收改为逐条提交，避免清理大事务耗尽数据库内存。

## 兼容说明

- 旧执行快照继续支持恢复，不随本次升级批量重写。
- 框架版本跟随本次锁定升级，本地开发与安装版共用同一套锁定源码。
