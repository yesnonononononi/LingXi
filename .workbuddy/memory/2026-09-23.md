4. **`/a/chat` 是 `multipart/form-data`**，不是 JSON body。
5. **AI 对话前置依赖**：必须有 `model_config` 记录且请求带 `modelId`（或用户 `common_config.model_id`），
   否则返回"未找到模型"。`common_config` 按 user_id 唯一，新用户默认无记录。

## 【补充】修复启动崩溃：NoClassDefFoundError: io/netty/resolver/dns/DnsCache

用户在 20:45 遇到新的启动失败，堆栈链路：
`chatController → chatServiceImpl → IChatAgent → defaultRuntimeFactory → defaultRuntimeListener
→ agentEventListener → sseEventPublisher → redissonClient` → `Factory method 'redissonClient' threw exception`
→ `NoClassDefFoundError: io/netty/resolver/dns/DnsCache`（`org.redisson.config.Config.<init>` 触发）。

### 根因
**Netty 版本被 Spring Boot BOM 强制降级**：
| 来源 | Netty 版本 | 说明 |
|---|---|---|
| `redisson-parent:4.7.0` 导入的 `netty-bom` | 4.2.16.Final | Redisson 按此版本编译 |
| `spring-boot-dependencies:3.5.6` | 4.1.127.Final | dependencyManagement 优先级更高，实际生效 |

排查依据：`dependency:tree -Dincludes=io.netty:*` 输出中每条都带
`(version managed from 4.2.16.Final)`，明确指向被 Spring Boot 的 `netty.version` 属性覆盖。
`DnsCache` 类在 4.1.127 与 4.2.16 两个 jar 中都存在，因此**不是版本缺类，而是编译期/运行期 API 不匹配**。

### 修复
`pom.xml` 的 `<properties>` 中新增：
```xml
<netty.version>4.2.16.Final</netty.version>
```
Spring Boot 正是通过该属性管理 netty 全族版本，覆盖后 13 个 netty 组件全部统一到 4.2.16.Final。
修复后：`Started LingXiApplication in 5.489 seconds`，Redisson 4.7.0 正常建立 24 个连接，
Swagger / 注册 / 登录 / 工具列表 / 工作空间列表回归测试全部通过。

## 【大重构】去分布式化 —— 转为纯本地 harness

架构判定：框架侧完全符合"提供可暂停/恢复/终止的 loop + 分布式接入点（无分布式语义）"的边界。
框架自述 `RuntimeContext` 注释：**"the runtime itself carries no product semantics"**。
框架自带实现只有 `InMemoryActiveExecutionRegistry`（单进程 ConcurrentHashMap + Signal），
跨节点互斥/租约/恢复原本全在业务侧的 `JdbcExecutionPersistenceRepository` 里 —— 所以本次是删业务代码，不碰框架。

### 关键设计认知（框架边界）
- 框架的 `ExecutionPersistenceRepository` 是**空接口**，`ExecutionRuntimeConfig` 里
  `distributed-enabled=false`（默认）时返回 `InMemoryActiveExecutionRegistry`，
  `=true` 时若业务没提供 bean 则**直接抛异常**——框架不提供任何 DB/Redis 实现。
- 框架 loop 是**协作式**控制：在循环边界读 `ExecutionControlSignal.intention`（volatile），
  非抢占式中断。跨节点投递不在框架职责内。
- `ExecutionControlSignal` 只有 `NONE / REQUIRE_SUSPEND / REQUIRE_CANCEL` 三态，无租约概念。
