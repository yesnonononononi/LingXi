怎么一眼判断这是 wink 而不是「双眼闭合」或「整头重绘」

  • 睁眼侧必须还是那只蓝色大眼：右侧眼区在 E1/E9 里完全一样（差异像素 0）。若两边都闭着，那是 E2_blink，不是 wink。
  • 嘴型 / 腮红 / 发夹 / 刘海一点都不能动：把「闪切对比」打开，盯住鼻子以下的区域——它应该纹丝不动；只有左侧眼睑在动。
  • 闭眼笔迹与 blink 同一笔迹：E9 的闭眼取自 E2_blink 的左眼，所以眨眼与 wink 的眼睑风格一致，不会出现两套笔触。
  • 闭合弧线上挑、嘴角不变：眼睑内角略微上挑读作俏皮，而嘴角保持中性 :3，避免与 happy 混档。
  • 命令复核：node docs/assets/desktop-pet/v4/tools/check-wink.mjs（全绿才可入库）。

本页不做什么

  • 不做任何缩放插值以外的图像处理：放大用 image-rendering: pixelated，看到的就是母版原像素，不是渲染效果。
  • 不引用 manifest（file:// 下 fetch 会被 CORS 拦），数字以 README 与 manifest.json 为准。
  • 闪切在 prefers-reduced-motion: reduce 下不自动播放，只保留手动按钮。
