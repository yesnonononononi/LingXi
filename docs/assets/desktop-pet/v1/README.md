## 使用边界

立绘可作为静态显示素材和后续拆件基准。表情图仅供表情设计参考，各格并非像素对齐的动画帧；边缘留白也不足以直接裁成统一帧。

尾巴是独立补绘草案，轮廓与原画存在差异，须调整位置、比例和遮挡关系后才能组装。生成素材边缘仍须在深浅背景上复核并清理。

本批未交付分层 PSD、完整遮挡补绘、Cubism 工程或可运行的 Live2D 模型。

已目视检查三张生成图，并验证 PNG 可解码、尺寸和 alpha 通道；四角抽样包含全透明像素。尚未完成逐像素边缘清理及桌宠实际尺寸验收。

## 后续制作

1. 固定原画尺寸与共用坐标，先完成头发、耳朵、脸底、身体及尾巴的分层和补绘。
2. 将左右眼白、虹膜、高光、上下眼皮、眉毛与口型拆成独立部件。
3. 在共用画布重组验收，检查摇头、眨眼和尾巴摆动时的接缝，再进入 Cubism 绑定。
