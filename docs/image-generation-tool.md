# 生图工具

在「设置 → 模型 → 其它模型配置」分别选择压缩模型和生图模型。生图模型仍在模型列表维护连接信息，调用方式选「图片模型」；对话与智能体基座选择文本模型。

主模型根据完整会话组织提示词，再调用 `generate_image`：

```json
{"prompt":"夕阳下的红色帆船，白帆，插画风格","path":"art/sailboat.png"}
```

`size`、`quality`、`count` 都可以不传，只有 `prompt`、`path` 必填。默认尺寸优先采用生图模型配置；未配置时为 `1024x1024`。默认质量沿用模型配置，未配置则由服务端决定。每次只生成一张图片，`count` 默认且仅支持 `1`，不会继承模型配置中的批量数量。

需要覆盖规格时：

```json
{"prompt":"夕阳下的红色帆船，白帆，插画风格","path":"art/sailboat-wide.png","size":"1536x1024","quality":"high"}
```

本地只做基础格式校验：`size` 必须为正整数宽x高（如 `1536x1024`）或 `auto`，`quality` 必须为非空白字符串。工具不维护模型白名单、尺寸档位、边长、比例、像素数或质量枚举限制。格式正确的规格直接交给模型；服务端拒绝时，工具返回包含服务端错误信息的失败结果，供主模型决定如何调整参数。

- `path` 必须为工作区内的相对文件路径，支持 `.png`、`.jpg`、`.jpeg`，已有文件不覆盖。
- `reference_image_path` 可选，传入工作区内单张 PNG/JPEG 的相对或绝对路径即可润色；省略时按文字生成。参考图不超过 16MB、4000 万像素，按文件头识别格式并验证解码，保持原图字节与透明通道。越界路径、指向外部的链接、损坏图片均在模型调用前拒绝。
- 文件通过工作区桥接写入，本地和沙箱共用此工具。预览副本位于数据目录，通过 `/a/images/...` 查询。
- 回执提供 `path`、`previewUrl` 和文件大小。主模型可用 Markdown 图片展示预览，继续执行其它任务。
- 生图模型的用量汇总到当前执行；生成成功但保存失败时，已返回的模型用量仍计入。

`user_configs` 新增设置字段：

| 字段 | 含义 |
| --- | --- |
| `imageModelId` | 生图模型 ID；显式 `null` 关闭，不传保持原值 |
| `imageGenerationMaxCalls` | 每次执行最多调用次数；默认 10，范围 0～20，0 禁用 |

次数按工具调用计数，失败也占用。调用前保存执行配额，同一轮多个请求共用上限；暂停、恢复不会重置，新执行单独计数。SDK 自动重试关闭，避免一次工具调用隐含多次生成请求。

参考图润色示例：

```json
{"prompt":"保留人物、构图和透明背景，润色线条并改善光影","reference_image_path":"art/original.png","path":"art/polished.png","size":"1024x1024","quality":"high"}
```

模型只传文件路径，不传 Base64，也不要求先调用 `read_image`。后端通过工作区桥接读取原图，构造带 MIME 类型的 Base64 图片对象；SDK 将其解码成文件字节，通过 multipart 上传到 `/images/edits`。原图不会作为工具回执写进主模型上下文。文本主模型不需要视觉能力即可按明确指令编辑；需要先观察内容时再使用 `read_image`。

编辑沿用本次尺寸、质量、配额、用量汇总与另存预览规则。图片模型和服务端必须支持编辑接口；不支持时返回实际错误，不自动改成文生图。目前仅支持单张参考图，可附带蒙版。

蒙版编辑与透明输出：

```json
{"prompt":"只润色蒙版透明区域，保留其余结构","reference_image_path":"art/original.png","mask_image_path":"art/mask.png","path":"art/polished.png","background":"transparent","output_format":"png"}
```

`mask_image_path` 可选，支持工作区内相对或绝对路径；必须同时传参考图，蒙版必须为同尺寸、带 alpha 通道的 PNG，并至少有一个完全透明像素。完全透明区域指示待编辑位置；模型是否严格保持其它区域仍需另行比对。蒙版沿用单图文件、像素及工作区边界限制。

`background` 可选 `transparent`、`opaque`、`auto`；`output_format` 可选 `png`、`jpeg`，必须与保存路径扩展名一致。请求透明背景时必须保存为 PNG，省略输出格式会自动请求 `png`。这些是本次调用选项，不新增模型设置界面。

选项通过框架传给 SDK 原生字段，是否受模型和网关支持由服务端决定。显式请求格式时，服务端原始图片格式不符即失败，不先转码。透明输出必须带 alpha 且存在完全透明像素；不透明输出不能含透明或半透明像素。不符合要求时不保存为成功结果，但已返回的模型用量仍入账。通过像素检查不代表抠图边缘或主体轮廓符合资产要求，仍需视觉和几何验收。

多图输入暂不接入，保持一次输入底图、可选蒙版、输出一张图片。

设置沿用现有 JSON 配置仓储。H2 的 V2 脚本同步补齐表字段，V1 基线指纹保持原样。升级后重启后端，在其它模型配置中选择已有图片模型即可使用；历史图片消息继续使用原渲染链路。
