# 子会话上下文用量展示

- 分支：`codex/sub-session-context-usage`，从 `90927df` 创建独立工作树，主工作目录的在飞改动不带入。
- 位置：子会话面板名称右侧，详情抽屉名称旁同步接入。圆环沿用 `ChatInputContextUsage`，输入区与子会话共用格式化函数。
- 数据：按自身 sessionId 读取实时用量，无实时值时读取该子会话的历史快照；未采集时隐藏。上下文窗口上限不借用根会话或模型输出上限。
- 浮层：样式沿用原组件，标题栏通过页面级浮层避免裁剪，适配窄屏、键盘聚焦与 Escape。输入区既有浮层触发范围保持原样。
- 本次接入既有实时事件与会话快照，未扩展采集频率或更改快照新鲜度策略。

## 验证

- `subSessionContextUsage.test.ts`：格式、缺失值、压缩文案、超限比例与圆环封顶。
- `subSessionContextUsage.smoke.cjs`：真实组件验证名称右侧位置、历史加载、实时更新、根子隔离、子会话切换、无数据隐藏、明暗主题、长名称、360px 窄屏与浮层边界。
- `chatInputSlots.smoke.cjs`：既有 7 条输入区插槽契约通过。
- 五项行为变异均触发断言失败：禁用实时来源、误用根会话 ID、取消页面浮层、圆环移到名称左侧、百分比换算错误。
- 冒烟页面保存在工作树自身 `.run/`，避免共享 node_modules 时解析到主目录源码；新增测试接入 test、test:all 和 test:smoke。

验证结果：完整 `npm test` 与 `npm run build` 均通过；输入区 7 条插槽契约单独通过。
