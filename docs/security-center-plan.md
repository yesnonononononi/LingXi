# 安全中心实施方案

恢复点：框架 e66f5a5，业务 b3307cd。发布工作流须由用户另行批准。

## 产品与边界

沿用现有设置弹窗的字体、灰阶、圆角和深浅色，新增安全中心入口，分为文件、命令、网络三个页面。顶部显示生效范围与执行层，列表沿用截图的预设标签、操作选择、添加、删除、恢复默认布局。

文件：默认仅当前工作区；可显式授权额外项目目录。预设和自定义保护路径均先于允许规则，禁止或只读约束由 MXC 强制覆盖命令及子进程。禁止、只读、读写为真实支持的三档，写入与删除不拆开；无法用弹窗拦截任意子进程文件访问。预设不自动授权凭据读取。环境变量路径在宿主端展开，未知变量拒绝保存。

命令：预设危险程序与自定义命令前缀支持拒绝、询问、允许；拒绝优先，其余按列表匹配。命令规则仅检查工具提交的命令，不声称检测任意脚本和所有子进程；文件和网络隔离继续约束它们。询问接入既有持久化审批，批准后执行前重新检查最新拒绝规则。

网络：默认拒绝，支持 TCP/UDP 的数字 IP/CIDR 与端口预设和自定义规则，拒绝优先。禁止把域名解析到共享 IP 后冒充域名隔离。域名、HTTP 分类、恶意站点库和动态网络询问在缺少实际代理实现时不提供虚假开关。回环仍保持禁止。

配置经后端校验并由现有用户配置仓储持久化。文件/网络策略为每个新工作空间快照；命令规则在每次工具执行和批准重放前检查。界面明确提示需新建会话才能切换文件与网络策略，保存失败保留编辑内容。

## 工作流与验收

1. 保存恢复提交，清理重复授权与旧语义。
2. 框架提供通用拒绝路径与网络规则，不内置业务隐私目录；不支持的能力在启动前拒绝。
3. 业务持久化与校验、策略编译、命令审批；前端加载、增删、排序、重置与保存。
4. 单元测试覆盖拒绝优先、参数校验、持久化回读、审批；原生 Windows 测试覆盖跨项目允许、隐私读写拒绝、子进程拒绝、网络拒绝与允许。前端用真实组件运行截图与交互验证。
5. 框架新版本提交推送并本地安装，业务锁定精确 SHA 与版本，再提交推送。禁止自动发布。
