# 安全中心实施方案

恢复点：框架 e66f5a5，业务 b3307cd。发布工作流须由用户另行批准。

## 最新范围

以工具规则与审计为产品模型，普通路径不再按当前工作区围栏。文件、终端、网络三类规则各自使用本地 JSON 表：sandbox-security-rule-files.json、sandbox-security-rule-terminal.json、sandbox-security-rule-net.json。业务负责预设、校验、持久化、界面与审批；框架负责通用规则匹配、访问前检查与裁决结果。预设和自定义规则共享同一执行入口。

网络第一版不拦截：允许外网、局域网、回环、HTTP/HTTPS，以及远程和 stdio MCP。网络页明确显示“默认允许，尚未启用过滤”；网络表先保存当前策略，拒绝保存无法执行的过滤配置，不提供假生效的拦截开关。原生隔离后端若不能放行全部方向，不能静默保留局部限制再声称网络完全放行。

文件规则按读取、写入、删除独立配置；未命中允许。按规范化路径和真实路径匹配，覆盖相对路径、大小写、目录边界、符号链接与 junction。规则顺序只在同类允许规则中生效，拒绝优先，防止新增宽泛规则覆盖敏感目录保护。配置文件、审计文件和应用控制文件另有不可由普通允许规则覆盖的自保护规则。

终端规则支持程序名和命令前缀，允许、询问、禁止；复用现有命令审批。命令文本匹配不等于任意脚本或子进程的系统调用拦截，界面必须明确这一点。不能用命令字符串扫描冒充隐私隔离。

## 文件审批的改动量与性价比

静态证据：现有持久化审批只处理 COMMAND、PLAN、CHOICE；文件工具直接调用 WorkspaceBridge。文件读写审批不能仅增加一个枚举值。

| 方案 | 所需改动 | 第一版判断 |
| --- | --- | --- |
| 文件工具访问前允许或拒绝 | 通用路径匹配和桥接检查、三表仓储、设置接口与界面、审计与回归 | 成本相对较低，可以先交付 |
| 文件工具逐次询问 | 新文件审批载荷和渲染、挂起恢复、读写删执行器、单次授权、审批后参数/内容/路径重校验、取消与重启恢复、并发与事务测试 | 中到高成本；会把编辑工具内部多次 exists/read/mkdir/write 合并成一次用户意图，不能逐次弹窗 |
| 任意终端和 MCP 子进程文件访问询问 | OS 拦截代理或文件系统过滤层、进程与执行归属、阻塞线程安全、死锁与超时、跨平台实现 | 与前两项不是同一级别；本轮不把它当作普通弹窗功能 |

建议第一版不引入文件询问，采用 ALLOW / DENY。ASK 保留在接口动作枚举内，但文件页面不展示且后端拒绝保存，避免选中后没有执行路径。命令询问继续可用。后续即使加入询问，也建议保留 DENY，永久禁止具有独立价值。

## 待确定的保护边界

需要区分两种不同的产品承诺：工具前置规则能拒绝直接文件工具访问，但宿主进程中的终端脚本或 MCP 可自行读文件；原生进程隔离可覆盖这些读取，却不能只靠已有规则引擎实现逐次询问。已向用户确认第一版需要哪一种覆盖范围；在答案到达前先完成两种方案都需要的配置模型与界面。

## 规则表和接口契约

每类表保存一个带 revision 的完整规则集合，通过现有 AbstractJsonRepository 使用文件锁、原子替换与事务支持。规则为无独立身份的值对象，新增表单不伪造业务 ID；预设由服务端生成。保存携带读取时的 revision，冲突拒绝并保留本地编辑，避免多窗口覆盖。

GET /sandbox/security/{files|terminal|net} 返回规则、revision、支持的动作、实际执行范围及未命中动作。PUT 同路径校验并保存完整集合，返回新的权威 revision。POST /sandbox/security/{category}/defaults 返回预设草稿，用户保存后生效。网络默认允许由服务端固定，不接受不能实施的拦截规则。

## 界面与验证

保留项目现有字体、灰阶、圆角、深浅色和设置控件。安全中心包含文件、命令、网络三页，参照截图的预设标签、操作选择、增删排序和恢复默认布局，顶部显示实际执行范围。加载失败不生成假配置；保存失败保留编辑；明确保存生效时机。

验证包括本地 JSON 回读、并发版本冲突、预设与自定义、路径别名与目录边界、拒绝优先、命令询问/重放、网络与远程 MCP 正对照、中文输出和长消息回归；真实组件运行交互和深浅色截图。断言保护范围以实际运行证据为准。

## 后续工作顺序

模型与界面完成后，根据用户确定的保护边界实现执行层。框架测试通过后升级版本、提交推送并本地安装；业务锁定准确 SHA 和版本，再完成业务验证、提交推送。保留原生适配器代码作为可恢复能力，不把无进程隔离的模式伪称为原生隔离。正式发布、打标签及上传安装包均等待用户批准。
